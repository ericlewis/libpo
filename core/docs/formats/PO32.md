# PO-32

[Format overview](../PO_FORMATS.md) · [Documentation](../README.md)

See [the protocol reference](../PROTOCOL.md) for tags and offsets. The one-byte
`496F` pattern-slot record appears in place of full pattern records. A
[captured regression fixture](../../tests/test_core.c) contains marker `03` and
state chain `[03]`, so a marked slot can be in the chain. Its precise receive
action remains unmodeled; raw parsing preserves it.

The 16 pattern bytes at offsets 193..208 contain independently varying data,
not disposable padding. Official pattern pairs differ only in this region
apart from their slot number. A per-step effect/control role is a candidate;
effect names and high-nibble behavior are not established. The trailing accent
mask can contain bits beyond the active trigger accents.

For candidate packed FX/reference semantics, independently retained accent
state and the possible pitch role of the parameter-pair `flag` byte, see the
[PO-32 hypothesis map](FIELD_HYPOTHESES.md#7-po-32-packed-fx-history-accent-state-and-the-misleading-flag-name).
The [FX/reference follow-up](PO32_EFFECTS_STATE.md) adds original Microtonic
exporter evidence and tests absolute versus relative references across the
retained capture archive.

The [lossless record codecs](../api/PO32.md#lossless-state-and-pattern-records)
preserve complete state and full-pattern payloads. `po32_state_raw_t` retains
ordered chains through the packet's 220-entry capacity; `po32_pattern_raw_t`
retains every trigger bit, parameter pair, reserved byte and accent-mask bit.
Selective trigger edits can use the existing `po32_pattern_control_t` view.

Two limits remain in the older semantic packet API for compatibility:

- `po32_state_packet_t` holds 16 chain entries. Official Basic Beats 1 contains
  22 ordered entries with repetitions. The new raw state codec preserves them;
  the legacy generic state decoder still rejects them.
- Typed pattern encoding writes zero for an inactive instrument. Some valid
  captures retain selector/accent bits in otherwise inactive trigger bytes,
  so its decode/encode is not always byte-identical. The raw pattern codec and
  raw packets preserve those bytes. Both codecs retain the reserved region and
  accent mask.

The frame parser and streaming demodulator admit state payloads of 35..255
bytes. The new record codec requires exactly 35 bytes plus the stored chain
count, giving a 220-entry software capacity. Neither that capacity nor the
captured 22-entry chain establishes the device maximum. Count/length mismatches
and trailing extensions remain raw packets; the record codec rejects them
rather than discarding bytes.

`po32_pattern_control_t` supplies a separate lossless view of each raw trigger:
bits 0..3 are the fill code, bits 4..5 the instrument group, bit 6 remains
unassigned, and bit 7 is accent. Its codecs preserve every byte value; existing
semantic trigger and pattern conversions retain their normalization behavior.
Preserving an unassigned bit does not establish its playback meaning.

Regression fixtures include the official Basic Beats 1 chain and a pattern
with retained inactive selector/accent bits. Exhaustive synthetic trigger tests
also cover bit 6, which was not present in the inspected capture corpus.
